VOICE MESSAGE BOOSTER POUR VENCORD
=================================

Installation :
1. Extrais complètement le ZIP.
2. Double-clique sur Installer.cmd.
3. L'installateur copie le build dans :
   %LOCALAPPDATA%\VoiceMessageBooster\VencordData
4. Active ensuite VoiceMessageBooster dans :
   Discord > Paramètres > Vencord > Plugins

Aucun Git, Node.js ou pnpm n'est nécessaire sur ton PC.
Le script télécharge uniquement le Vencord Installer CLI depuis le dépôt officiel Vencord.

Le build désactive l'auto-updater Vencord afin qu'une mise à jour officielle ne supprime pas le plugin privé.
Pour mettre à jour le plugin, télécharge la release la plus récente et relance Installer.cmd.

Attention : augmente progressivement le gain pour protéger ton audition.
